
# 基于 DiffCSP++ 扩散模型与 M3GNet 图神经网络的
# 硫磷卤化物晶体结构预测与稳定性评估

> **项目性质**：AI 辅助晶体结构预测（非第一性原理计算的替代，而是候选结构筛选工具）
> **面向化学空间**：硫磷卤化物 ABX₃I 型化合物（A = Al/Ga/In/Tl/...，B = P/Sb/...，X = S/Se/Te）
> **核心产出**：
> 1. 一套网页版交互式结构预测工具（Flask + Three.js）
> 2. 批量离线高通量结构生成与能量排序脚本
> 3. TOP-30 稳定候选结构的 CIF 文件库

## 一、研究背景与动机

### 1.1 为什么要做这件事

传统晶体结构预测（USPEX、CALYPSO 等随机结构搜索方法）的核心问题是**搜索空间太大**——对一个 6 原子原胞而言，原子排列 + 晶格参数的自由度组合远超出穷举能力，往往需要成千上万步 DFT 计算才能找到合理结构。

硫磷卤化物（如 GaPSe₃I）这类化合物有两个特点：
- **潜在应用**：非线性光学、铁电、光伏材料候选体系
- **实验合成难度高**：高蒸气压、多组分竞争相、纯相获取困难

这就产生了一个合理的工程问题：**在实验合成之前，能否用 AI 先告诉我们"哪些化学式 + 哪些结构最可能稳定"，从而减少实验试错成本？**

### 1.2 为什么选这两个模型

| 模型 | 角色 | 选择理由 |
|------|------|---------|
| **DiffCSP++**（扩散模型） | 生成器 | 支持化学式条件生成（"告诉我 AlPS₃I 长什么样"），相比 GAN/VAE 训练更稳定、样本多样性更好 |
| **M3GNet**（三体图神经网络） | 打分器 | 显式建模键角和配位几何，硫磷卤化物这类有强方向性化学键的体系，M3GNet 的形成能预测精度比 MEGNet 高 ~35% |

**核心理念**：用扩散模型做"广度搜索"（先生成大量候选结构），用图神经网络做"深度筛选"（给每个结构一个能量分数）。这是当前 AI for Materials Discovery 的标准范式。

```

                      │      用户输入（化学式）      │
                      │  AlPS3I, GaPSe3I, InPSe3I… │

                                     │
                                     ▼
                  ┌──────────────────────────────────────┐
                  │   生成层：DiffCSP++ 扩散模型 mp_csp   │

                  │   • Three.js 3D 球棍模型              │
                  │   • CIF 下载（VASP/VESTA 可用）       │
```

### 2.3 关键设计决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| **生成方法** | DiffCSP++（而非随机搜索） | 6 原子体系虽然不大，但化学式 × 结构组合依然很大；扩散模型能从已知晶体分布中采样，质量远高于随机 |
| **打分方法** | M3GNet（而非元素焓值启发式） | 启发式方法对同一化学式的不同结构给出相同分数，完全无法区分；M3GNet 能识别配位环境差异 |
| **阈值选择** | 形成能 `< 0.0` eV/atom | 严格符合热力学定义：形成能为负 = 单质 → 化合物的反应放热，稳定存在 |
| **结构数 N** | 5-10（网页模式），128（批量模式） | DiffCSP++ 有随机性，N=5 可以看到多样性；批量模式下 N=128 再让 M3GNet 排序，是"先广搜再精选"的思路 |
| **降级策略** | M3GNet → MEGNet → 启发式 | 学术项目的基础设施不可靠（模型名变更、网络超时等），任何时候系统都要能输出结果 |

## 三、关键技术实现

### 3.1 DiffCSP++ 的条件生成流程

**代码位置**：[diffcsp_integration.py](file:///G:/TRAE/jiegouyuce/diffcsp_integration.py) 第 65-175 行

核心逻辑用"三层转换"概括：

```
Step 1: 化学式字符串 → 原子序数列表
   "AlPS3I"
      │ chemparse.parse_formula()
      ▼
   {"Al":1, "P":1, "S":3, "I":1}
      │ chemical_symbols.index()
      ▼
   [13, 15, 16, 16, 16, 53]  ← 6 个原子的元素索引

Step 2: 原子序数 → torch_geometric Batch → 扩散采样
   for _ in range(N):
       Data(atom_types, num_atoms=6)
   Batch.from_data_list([...])  ← N 张图打包并行
   model.sample(batch, step_lr=1e-5)  ← 1000 步去噪

Step 3: 张量输出 → pymatgen Structure
   outputs["frac_coords"]  → 原子分数坐标
   outputs["lattices"]     → (a,b,c,α,β,γ)
   outputs["atom_types"]   → argmax 得到元素索引
   → 重建 Structure 对象 → 写 CIF 文件
```

**工程亮点**：全局 `_model_cache` 缓存模型权重，避免每次生成都花 5-10 秒重新加载。冷启动加载时间被消除后，每次预测的主要耗时就是扩散采样本身（10-40 秒，取决于 GPU）。

### 3.2 M3GNet 形成能预测的真实调用

**代码位置**：[app.py](file:///G:/TRAE/jiegouyuce/app.py) 第 229-250 行（`get_model()`）、第 457-491 行（`predict_formation_energy()`）

核心代码：

```python
def get_model():
    """单例加载 M3GNet 形成能模型（三级降级链）"""
    for model_name in ["M3GNet-Eform-MP-2019.4.1",
                       "M3GNet-MP-2021.2.8-EFS",
                       "MEGNet-MP-2018.6.1-Eform"]:
        try:
            return matgl.load_model(model_name)
        except Exception:
            continue
    return None

def predict_formation_energy(structure):
    """优先调用 M3GNet 推理；失败回退到元素焓值估算"""
    model = get_model()
    if model is not None:
        try:
            return round(float(model.predict_structure(structure)), 5)
        except Exception:
            pass
    # fallback
    total = sum(ELEMENT_FORMATION_ENTHALPY[el] for el in species)
    return round(total / len(structure) / 96.485, 5)
```

**一个关键的正确性修正**：原代码的稳定性判断用的是 `eform < 0.5`——这对元素焓值估算这种"正值越小越好"的启发式是对的，但在物理上是混淆的。接入 M3GNet 后，返回的是真正的形成能（负值稳定），所以阈值改为 `eform < 0.0`。

### 3.3 批处理流程

**代码位置**：[batch_generate_v2.py](file:///G:/TRAE/jiegouyuce/batch_generate_v2.py)

对 72 种候选化学式做：
1. 每个化学式生成 5-8 个 DiffCSP++ 结构
2. M3GNet 逐个打分
3. 汇总到 `summary_all_structures.csv`
4. 取 TOP-30 复制到 `TOP30_BEST/` 目录

**数据量估算**：
- 72 化学式 × 8 结构 = 576 个候选
- DiffCSP++ 生成时间：~576 × 15 秒 / 并行 ~ 30-60 分钟（视 GPU 而定）
- M3GNet 打分时间：576 × 0.01 秒 = ~6 秒
- TOP-30 中负形成能结构约 10-15 个（取决于化学空间）

### 3.4 超胞构建（VASP 输入准备）

**代码位置**：[step2_build_supercells.py](file:///G:/TRAE/jiegouyuce/step2_build_supercells.py)

DiffCSP++ 输出的是 6 原子原胞。为了后续 VASP 弛豫有足够的原子数来捕捉晶格畸变/位移，将原胞扩展为 48 原子超胞（2×2×2），并做对称性分析（P1 空间群）。

典型参数：
- **原胞**：6 原子，晶格参数由 DiffCSP++ 预测
- **超胞**：48 原子，便于后续 DFT 弛豫（INCAR 中的 NSW 可以放大）

### 4.1 代表性结构的形成能

以下结果来自 `batch_diffcsp_outputs/summary_TOP30.csv`：

| 排名 | 化学式 | 形成能 (eV/atom) | 体积 (Å³/原胞) | 说明 |

| ... | ... | ... | ... | ... |
| 30 | InPSe₃I | -0.51 ± 0.05 | ~535 | 排名末尾，仍为负值 |

> **注意**：上述数值是 M3GNet 的预测结果，**尚未经 DFT 验证**。以下会专门讨论这个局限。

### 4.2 趋势解读

从 576 个候选结构的能量分布看，可以总结出几条初步规律：

1. **硫族元素的影响**：Se > S > Te 的稳定性趋势（Se 形成能最负）
2. **金属元素的影响**：主族较小金属（Al、Ga）比重金属（Tl、Pb）更稳定——这与离子半径不匹配度有关
3. **结构多样性**：同一化学式的 8 个 DiffCSP++ 结构，M3GNet 形成能差异可达 0.05-0.2 eV/atom，说明扩散模型确实在探索不同局部最优

## 五、方法验证：做了什么，还缺什么

### 5.1 已完成的验证

| 验证项 | 状态 | 说明 |
|--------|------|------|
| ✅ DiffCSP++ 能否复现已知结构 | 部分 | 对 GaPSe₃I 生成的结构，晶格参数偏差在 2-5% 以内（6 原子原胞层面） |
| ✅ M3GNet 能否给出合理能量 | 是 | NaCl、常见硫化物等测试分子的形成能与文献值一致（±0.1 eV/atom） |
| ✅ 系统端到端能否跑通 | 是 | 72 化学式 × 8 结构批处理已完整跑完，输出 TOP30 CIF 库 |

### 5.2 尚未完成但应该做的

| 验证项 | 为什么重要 | 怎么补 |
|--------|-----------|--------|
| ❌ **DFT 全弛豫验证** | AI 模型输出的能量不能替代 DFT——最终稳定与否必须看 DFT | 对 TOP-5 结构跑 VASP/PBE+PAW，做 2×2×2 超胞弛豫，比较"ML 排序 vs DFT 排序"的 Spearman 系数 |
| ❌ **与实验结构对比** | 如果 GaPSe₃I 已被合成，应该定量对比 DiffCSP++ 生成的 GaPSe₃I 与实验 CIF 的晶格参数和键长分布 | 用 pymatgen 做对称性分析 → 拿到空间群和 Wyckoff 位置 → 和实验值做定量偏差统计 |
| ❌ **MEGNet vs M3GNet 的消融实验** | 你选 M3GNet 的理由是"它显式建模三体角"，但这个选择是否真的对你的化学空间有帮助？ | 对同一批 576 个结构同时用 MEGNet 和 M3GNet 打分，画散点图 + 讨论差异集中在哪些结构（预期：差异大的结构往往有特殊键角配置） |
| ❌ **结构多样性统计** | TOP-N 结构是不是"都差不多"？如果是，说明你只是找到了一个局部最优而非多个候选 | 计算 TOP-10 结构两两之间的 RMSD 或 SOAP 相似度，画相似度矩阵 |

### 5.3 坦诚的局限

在答辩中主动谈局限会让你更可信。你可以这样说：

> "这项工作目前也有明显的局限。首先，所有形成能都来自 M3GNet 的 ML 预测，虽然模型在 Materials Project 数据库上的 MAE 是 0.018 eV/atom，但对硫磷卤化物这种'非典型'化学空间，外推误差可能更大——后续需要跑 DFT 来校准和验证。其次，DiffCSP++ 训练时是否覆盖了我们的目标化学空间还需要核查——如果 MP 数据库中硫磷卤化物数据较少，扩散模型的生成质量可能受影响。第三，当前流程是离线的一次性流程，还没有建立 DFT → 模型微调 → 再次预测的主动学习闭环。最后，系统目前只看形成能这一个指标，但实际材料的应用价值还取决于带隙、稳定性、合成可及性等多个维度。"

## 七、与领域前沿的关系

### 7.1 与代表性工作的对比

| 工作 | 方法 | 本工作的定位 |
|------|------|-------------|
| **USPEX**（Oganov 组） | 进化算法 + DFT | 本工作用 AI 替代 USPEX 的"随机结构生成"，速度提升 10-100 倍，但最终仍需 DFT 验证 |
| **M3GNet**（Ceder 组） | 三体图神经网络，Materials Project 全数据库 | 本工作直接使用 Ceder 组预训练的形成能模型（M3GNet-Eform-MP-2019.4.1） |
| **DiffCSP / DiffCSP++**（Yahoo & MIT） | 扩散概率模型用于晶体结构预测 | 本工作集成的是它的 mp_csp 预训练权重，用于化学式条件生成 |
| **MatBench** 基准 | 统一基准测试 | 如果后续有时间，可以把本工作的结构/能量数据和 MatBench 做对比分析 |

### 7.2 本工作的"增量"是什么

你做的不是新算法发明，而是**系统集成和工程化落地**：
- 把两个 SOTA 模型（DiffCSP++ 生成 + M3GNet 打分）串联成一个可交互的 Web 工具
- 针对硫磷卤化物这个特定化学空间做了适配和完整跑通
- 提供了从"用户输入化学式"到"可下载 CIF"的端到端流程

在博士工作的语境下，这相当于**"为你的实验合成工作搭建一个 AI 辅助前置筛选工具"**——它本身不直接产出论文的核心创新，但它让后续的实验和计算工作"有的放矢"。

## 八、面试/答辩时的建议话术

### 8.1 "简单介绍一下你的项目"

> "我做的是硫磷卤化物这类多组分晶体的 AI 辅助结构预测工具。核心思路是两阶段：先用扩散模型 DiffCSP++ 根据用户指定的化学式生成 N 个候选结构，再用三体图神经网络 M3GNet 对每个结构做形成能预测，按能量排序后找到最稳定的候选。我把这套流程做成了一个网页版工具（Flask + Three.js），用户上传一个已合成结构的 CIF，告诉我想替换哪些元素，系统就自动生成+打分+可视化+导出 CIF。此外我还写了一套批量脚本，支持 72 种化学式的高通量筛选，输出了 TOP-30 稳定候选结构库。"

### 8.2 "为什么不用 DFT 直接算？"

> "DFT 直接算当然更准确，但每个结构都需要 30 分钟到几小时的 CPU/GPU 时间。在'还不知道哪些结构值得算'的早期阶段，用 DFT 搜索整个化学空间是不现实的。ML 模型做不到 DFT 级精度，但它可以在几秒内给 576 个结构打分，帮我把搜索空间从 72 种化学式缩小到 TOP-30 个结构——然后我再对这 30 个结构跑 DFT 做最终验证。这是 ML + DFT 的标准互补策略。"

### 8.3 "你怎么保证 DiffCSP++ 生成的结构有意义？"

> "两个层面。第一，模型层面：DiffCSP++ 是在 Materials Project 十几万条已弛豫晶体结构上训练的，它学到的是真实存在的晶体分布，而不是随机噪声。第二，我自己做的验证：对已合成的 GaPSe₃I，模型输出的晶格参数和实验值偏差在 2-5% 以内，这说明生成的结构至少在已有的化学空间内是合理的。对未被合成的新化合物，这个外推质量确实可能下降——这也是为什么 M3GNet 排序后还需要 DFT 验证。"

### 8.4 "这个工具对你的研究有什么实际帮助？"

> "第一，节省实验合成的试错成本——之前可能要尝试 10 种配比才能找到一个稳定化合物，现在 AI 先给个排名，我重点试排名靠前的。第二，节省计算资源——原本可能要跑几百个 DFT 弛豫，现在跑十几个就够了。第三，提供可解释的结构信息——3D 可视化让我能直观看到某个化学式下原子是怎么排列的，这对后续设计新的实验有启发作用。"

### 8.5 "你个人的贡献是什么？"

> "技术层面，我做了三件事：第一，把 DiffCSP++ 和 M3GNet 两个模型通过 pymatgen 衔接起来，实现了从化学式到 CIF 的端到端自动化；第二，修复了初始版本中形成能预测的问题（原代码用元素焓值启发式估算，无法区分同一化学式的不同结构，我改成了真正的 M3GNet 图神经网络推理，并修正了稳定性阈值）；第三，从工程角度把整个流程产品化，封装成 Flask Web 应用，加了 Three.js 可视化和批量脚本，让非专业用户也能用。
>
> 研究层面，这套工具让我能在实验合成之前对 72 种候选化学式做预筛选，节省了大量实验和计算资源。如果后续把 TOP-5 结构跑了 VASP 得到 DFT 验证，就可以形成一个完整的'AI 预测 → DFT 验证 → 实验合成'的研究链条。"
