## 第一部分：部署到 GitHub

### 第 1 步：在 GitHub 网站上创建空仓库

1. 打开浏览器，访问 https://github.com
2. 登录你的 GitHub 账号（用户名 Eag1e）
3. 点击右上角 **`+`** 图标 → 选择 **New repository**

   ![创建仓库位置](图片说明：右上角+号→New repository)

4. 在创建页面填写：
   - **Repository name**：输入 `crystal-structure-agent`
   - **Description**（可选）：输入 `LLM agent for crystal structure discovery — LangGraph + M3GNet + DiffCSP++`
   - **Visibility**：选择 **Public**（公开，让别人能看到）
   - **Initialize this repository with**：**全部不勾选！**
     - ❌ 不勾 Add a README file
     - ❌ 不勾 Add .gitignore
     - ❌ 不勾 Choose a license
     - （因为这些文件项目里已经有了，勾了会冲突）

5. 点击绿色的 **Create repository** 按钮

6. 创建完成后，你会看到一个页面，上面写着类似这样的命令：

   ```
   …or push an existing repository from the command line
   git remote add origin https://github.com/Eag1e/crystal-structure-agent.git
   git branch -M main
   git push -u origin main
   ```

   **先别关这个页面**，后面要用到这个地址。

### 第 2 步：生成 GitHub Personal Access Token（PAT）

GitHub 不允许用密码 push，必须用 Token。这一步只需要做一次。

1. 在 GitHub 页面，点击右上角头像 → **Settings**

   ![Settings位置](头像→Settings)

2. 左侧菜单滚到最下面，点击 **Developer settings**

3. 点击 **Personal access tokens** → **Tokens (classic)**

4. 点击 **Generate new token** → 选择 **Generate new token (classic)**

5. 填写 Token 信息：
   - **Note**：输入 `crystal-structure-agent push`（随便写，用于自己记住用途）
   - **Expiration**：选 **90 days** 或 **No expiration**（看你喜好）
   - **Select scopes**：勾选 **`repo`**（第一个大选项，全勾）
     - ✅ repo — Full control of private repositories

6. 点击页面最底部绿色的 **Generate token** 按钮

7. **⚠️ 极其重要**：页面上会显示一串 `ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` 的字符串
   - **立刻复制保存！** 复制到记事本里
   - 这个 Token 只显示一次，关掉页面就再也看不到了
   - 后面 push 代码时要当"密码"用

### 第 3 步：把本地代码推送到 GitHub

打开 **PowerShell**（Windows 搜索栏输入 PowerShell 打开），逐行复制粘贴执行：

```powershell
# 1. 进入项目目录
cd G:\TRAE\crystal-structure-agent

# 2. 设置 git 路径变量（后面所有命令都用到它）
$git = "G:\TRAE\PortableGit\bin\git.exe"

# 3. 添加 GitHub 远程仓库地址
#    （把 Eag1e 换成你的 GitHub 用户名）
& $git remote add origin https://github.com/Eag1e/crystal-structure-agent.git

# 4. 推送到 GitHub
& $git push -u origin main
```

### 第 4 步：完成身份认证

执行 `push` 命令后，会弹出一个认证窗口（Git Credential Manager）：

**方式 A：弹出窗口认证（最简单）**

如果弹出窗口：
1. 选择 **Token**
2. 在 "Password" 框里粘贴你刚才保存的 Token（`ghp_xxxxx`）
3. 点 **Log in**

**方式 B：命令行输入认证**

如果没有弹窗，命令行会提示：
```
Username for 'https://github.com': Eag1e
Password for 'https://Eag1e@github.com': （粘贴你的 Token，粘贴时不会显示字符，正常现象）
```

### 第 5 步：验证推送成功

1. 等命令执行完，看到类似输出：
   ```
   Enumerating objects: 230, done.
   Counting objects: 100% (230/230), done.
   Writing objects: 100% (230/230), 18.52 KiB | 1.54 MiB/s, done.
   To https://github.com/Eag1e/crystal-structure-agent.git
    * [new branch]      main -> main
   ```

2. 打开浏览器访问 `https://github.com/Eag1e/crystal-structure-agent`
   - 看到 220 个文件、README 渲染出架构图 → **GitHub 部署成功！**

3. 如果以后代码有更新，推送命令：
   ```powershell
   cd G:\TRAE\crystal-structure-agent
   $git = "G:\TRAE\PortableGit\bin\git.exe"
   & $git add -A
   & $git commit -m "描述你改了什么"
   & $git push
   ```

## 第三部分：部署到 Hugging Face Spaces

### 第 1 步：注册 Hugging Face 账号

1. 打开 https://huggingface.co
2. 右上角 **Sign Up**（支持 GitHub / Google 账号直接注册）
3. 用户名建议和 GitHub 一致：`Eag1e`

### 第 2 步：创建 Space

1. 登录后，点击右上角头像 → **New Space**

   ![New Space](头像→New Space)

2. 填写 Space 信息：
   - **Space name**：输入 `crystal-structure-agent`
   - **License**：选 `MIT`
   - **Select the Space SDK**：选择 **Streamlit**
   - **Space hardware**：选 **CPU basic · Free**（免费）
   - **Storage**：默认（Free CPU basic）

3. 点击 **Create Space** 按钮

4. 创建完成后，页面会显示 Space 的 Git 地址：
   ```
   https://huggingface.co/spaces/Eag1e/crystal-structure-agent
   ```

### 第 3 步：获取 Hugging Face Access Token

1. 点击右上角头像 → **Settings**
2. 左侧菜单 → **Access Tokens**
3. 点击 **New token**
   - **Name**：输入 `space-push`
   - **Type**：选 **Write**（必须有写权限才能 push）
4. 点击 **Create**
5. 复制 Token（格式类似 `hf_xxxxxxxxxxxxxxxxxx`），保存好

### 第 4 步：把代码推送到 Hugging Face Space

回到 PowerShell：

```powershell
# 1. 确保在项目目录

$git = "G:\TRAE\PortableGit\bin\git.exe"

# 2. 添加 Hugging Face 远程仓库
#    （把 Eag1e 换成你的 HF 用户名）
& $git remote add space https://huggingface.co/spaces/Eag1e/crystal-structure-agent.git

# 3. 推送到 Hugging Face
& $git push space main
```

### 第 5 步：完成 HF 认证

push 时会提示输入认证：
```
Username for 'https://huggingface.co': Eag1e
Password for 'https://Eag1e@huggingface.co': （粘贴 hf_xxxxxx Token）
```

> 如果之前 push GitHub 时存了凭证，这里可能不弹认证窗口直接用 GitHub 的 Token 报错。
> 解决办法：在 URL 里嵌入用户名，强制走命令行认证：
> ```powershell
> & $git remote set-url space https://Eag1e@huggingface.co/spaces/Eag1e/crystal-structure-agent.git
> & $git push space main
> # 这次只问 Password，粘贴 hf_xxxxxx
> ```

### 第 6 步：等待自动构建

1. push 成功后，打开你的 Space 页面：
   `https://huggingface.co/spaces/Eag1e/crystal-structure-agent`

2. 页面上会显示 **Building** 状态和构建日志

3. **等待 5-15 分钟**（首次构建要下载 torch 等 200MB+ 依赖包）

4. 构建完成后，状态变成 **Running**，页面显示 Streamlit 应用首页

5. 首页应该看到三个环境状态：
   - ✅ M3GNet 模型已加载
   - ⚠️ 或 ✅ API Key（如果还没配 Secret 就显示 ⚠️，下一步配）
   - ❌ CUDA 不可用（这是正常的！免费 CPU 环境没有 GPU）

### 第 7 步：配置 ZHIPU_API_KEY（让 Agent 有大脑）

1. 在你的 Space 页面，点击 **Settings**（Space 页面内的 Settings，不是账号 Settings）

2. 找到 **Variables and secrets** 区域

3. 点击 **New secret**：
   - **Name**：输入 `ZHIPU_API_KEY`
   - **Value**：粘贴你在第二部分申请的智谱 API Key

4. 点击 **Save** 保存

5. 保存后 Space 会自动重启（约 1-2 分钟）

6. 重启后再次打开应用首页，API Key 那项应该变成 ✅

### 第 8 步：验证在线 Demo

1. 打开 Space URL：`https://huggingface.co/spaces/Eag1e/crystal-structure-agent`

2. 首页检查三绿点（M3GNet ✅ / API Key ✅ / CUDA ❌ 正常降级）

3. 进入 **Agent Chat** 页面（左侧导航栏）

4. 在输入框输入：`浏览 GaPS3I 的结构`

5. 看到以下内容说明成功：
   - 意图识别显示 `browse`
   - 执行 `query_structure_library` 工具
   - 输出 GaPS3I 结构列表表格

6. 再试一个复杂查询：`找出最稳定的结构并分析它们的对称性`
   - 应看到 3 步链式执行：query → filter → symmetry
   - 最终输出 Markdown 报告

7. 进入 **Structure Library** 页面，筛选 GaPS3I，看到 3D 晶体结构渲染

**恭喜！你的在线 Demo 已经可以分享给别人了！**

## 常见问题排查

### Q: push 到 GitHub 时报错 `Authentication failed`

**原因**：Token 过期或没有 `repo` 权限。

**解决**：
1. 重新生成 Token，确保勾选 `repo` 权限
2. 更新凭证：打开 Windows 凭据管理器（控制面板→凭据管理器→Windows 凭据），找到 `git:https://github.com`，编辑或删除后重新 push 时重新输入

### Q: push 到 HF 时报错 `Authentication failed` 或 `403`

**原因**：HF Token 没有 Write 权限，或者凭证被 GitHub Token 覆盖。

**解决**：
```powershell
$git = "G:\TRAE\PortableGit\bin\git.exe"
# 在 URL 里嵌入用户名，强制走命令行认证
& $git remote set-url space https://Eag1e@huggingface.co/spaces/Eag1e/crystal-structure-agent.git
& $git push space main
# 这次只问 Password，粘贴 hf_xxxxxx
```

### Q: HF Spaces 构建失败

**排查步骤**：
1. 打开 Space 页面，查看 **Logs**（构建日志）
2. 常见错误：
   - `No module named 'xxx'` → 缺依赖，检查 `requirements.txt`
   - `ModuleNotFoundError: No module named 'torch_scatter'` → CPU torch 不含 scatter，可能需追加 `-f https://data.pyg.org/whl/torch-2.3.0+cpu.html`
   - `Port 7860 is already in use` → 不用管，HF 会自动换端口
3. 查看日志最下面的报错信息，针对性修复

### Q: Space 构建成功但页面显示 "Please wait..."

**原因**：冷启动需要加载 M3GNet 模型，约 5-15 秒。

**解决**：等一会儿刷新页面即可。

### Q: Agent Chat 页面显示 "API Key 未配置"

**原因**：Secret 没配或配错了。

**解决**：
1. 回到 Space Settings → Variables and secrets
2. 确认 Name 是 `ZHIPU_API_KEY`（全大写，完全一致）
3. 确认 Value 是有效的智谱 API Key
4. 保存后等 Space 自动重启

### Q: Agent 能用但功能不完整（规则模式 vs LLM 模式）

**正常现象**。无 API Key 时系统走规则兜底，意图识别和工具调度正常工作，但报告格式较简单。配了 API Key 后 LLM 会生成更智能的汇总报告。

### Q: Streamlit 本地能跑但 HF 上跑不了

**常见原因**：HF 的 Python 版本或包版本和本地不同。

**排查**：
1. 本地新建虚拟环境（`python -m venv test_env`）模拟 HF 环境
2. `pip install -r requirements.txt` 看能否安装成功
3. 如果本地装不上，HF 大概率也装不上
